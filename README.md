# Bon Prix Suiv | نظام تسيير المخزون، المندوبات والتوصيل 📦

تطبيق ويب متكامل ومتجاوب مع الهواتف الذكية وأجهزة الكمبيوتر باسم **Bon Prix Suiv**، مصمم خصيصاً لتجارة مواقع التواصل الاجتماعي التي تعتمد على المندوبات وعامل توصيل ميداني.

---

## 🌟 الهيكل والأدوار في Bon Prix Suiv:

### 1. لوحة تحكم صاحب المتجر (المدير 👑):
* **تسعير المنتجات وحساب أرباح التاجر:**
  * خانة لسعر الشراء (التكلفة عليك / رأس المال).
  * خانة لسعر بيعك أنت للمندوبة (سعر الجملة المعتمد للمتجر).
  * حساب آلي لحظي لربحك الصافي وللنسبة المئوية لكل قطعة.
* **إدارة المخزون والتنبيهات:** متابعة دقيقة لحركة المخزون وتنبيهات بنقص السلع.
* **إدارة أسعار التوصيل المرجعية:** جدول لجميع الولايات والبلديات الجزائرية لتحديد أتعاب التوصيل الرسمية.
* **إدارة المندوبات:** حساب الأرباح المؤكدة والمعلقة وتسجيل دفعات السحب.
* **زر عائم مخصص للهواتف الذكية:** لإضافة أي منتج جديد للمخزن بلمسة واحدة.

---

### 2. واجهة المندوبة (🌸):
* تصفح المنتجات المتوفرة وسعر المتجر الأساسي المعتمد لها.
* تسجيل طلبيات الزبائن وتحديد سعر البيع النهائي للزبون (بإضافة هامش ربحها).
* اختيار الولاية والبلدية مع إمكانية تخفيض سعر التوصيل، حيث يُخصم الفارق من أرباحها الصافية آلياً.
* حاسبة أرباح فورية ومتابعة المحفظة والطلبيات.

---

### 3. واجهة عامل التوصيل (🚚):
* بطاقات مهام التوصيل اليومية مع اتصال فوري وواتساب بنقرة واحدة.
* إبراز المبلغ الإجمالي المطلوب تحصيله عند باب الزبون (السلعة + التوصيل).
* **تبويب خاص بمستحقات التوصيل وحساباتي:**
  * احتساب مستحقات السائق على أساس **السعر المرجعي الذي حدده المدير** فقط (مثلاً 5 طلبيات إلى غرداية × 250 دج = 1250 دج).
  * كشف الكاش المحصل باليد وصافي المبلغ الواجب تسليمه للمتجر.
